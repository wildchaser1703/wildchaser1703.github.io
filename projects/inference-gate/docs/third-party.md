# Third-party assets

`gate/static` contains Swagger UI 5.17.14 from the public `swagger-ui-dist` npm
package, distributed under Apache-2.0. Its upstream license is included alongside
the assets. Vendoring allows the interactive API page to load entirely from
localhost. The project's Python source is MIT licensed.

Model: HuggingFaceTB/SmolLM2-135M-Instruct, Apache-2.0, pinned to revision
`12fd25f77366fa6b3b4b768ec3050bf629380bac`. Model weights are downloaded at runtime
and are not included in the source archive.
